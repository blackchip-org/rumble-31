Rumble 31

By Mike McGann

Featuring Claude Code

blackchip.org github

This classic card game of 31 is based on one of Mike's favorite MegaTouch games that has a similar name. I've always wanted one of those machines, but the next best thing is to vibe code the game yourself.

The closest ruleset that I could find that matches the original game is on the Dutch Wikipedia page for Eenendertigen. This implementation follows those rules, along with what I learned playing a MegaTouch at the System Source Computer Museum.
