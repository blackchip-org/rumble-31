# Changelog

## Version 12 - 2026-09-01

- Leaving and reopening the app now only resumes an in-progress game, or
  the game menu if it was open. Returning from any other screen — About,
  Stats, Settings, the difficulty picker, or the Game Over results — now
  opens the Main Menu instead of reopening that screen.

## Version 11 - 2026-08-27

**New**
- The app now works fully offline after it's loaded once, including
  when installed to your home screen.
- New builds are applied automatically in the background — no manual
  refresh needed to get the latest version.

## Version 10 - 2026-08-26

**Fixed**
- Game Over screen no longer overflows on short viewports, and its
  buttons fit better at typical window sizes.
- Settings screen no longer overflows on short viewports and its
  content is centered correctly.

## Version 9 - 2026-08-25

**New**
- Overhauled bot AI — Novice, Advanced, and Expert opponents now play a
  smarter strategy.

**Changed**
- Expert bot now favors trades that pair up cards or deny Aces from the
  pot, and plays more cautiously in one-on-one endgames to avoid handing
  the last opponent an easy win.
- Redesigned mobile-landscape layouts for the Main, Difficulty, Game
  Over, and Settings screens, with bigger buttons.
- Simplified the Stats screen's labels for wins-by-strikes and best
  hands.
- More spacing and taller buttons on the Game Menu screen.

**Fixed**
- Game table no longer overflows on common phone widths in
  mobile-landscape mode.
- Streak pill number and date now center properly on narrow portrait
  screens.
- Stats panel no longer overflows on short desktop viewports.
