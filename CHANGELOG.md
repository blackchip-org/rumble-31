# Changelog

## Version 9 - 2026-08-25

**New**
- Overhauled bot AI — Novice, Advanced, and Expert opponents now play a
  smarter strategy.

**Changed**
- Expert bot now favors trades that pair up cards or deny Aces from the
  pot, and plays more cautiously in one-on-one endgames to avoid handing
  the last opponent an easy win.
- Redesigned mobile-landscape layouts for the Main, Difficulty, Game
  Over, and Settings screens, with bigger buttons.
- Simplified the Stats screen's labels for wins-by-strikes and best
  hands.
- More spacing and taller buttons on the Game Menu screen.

**Fixed**
- Game table no longer overflows on common phone widths in
  mobile-landscape mode.
- Streak pill number and date now center properly on narrow portrait
  screens.
- Stats panel no longer overflows on short desktop viewports.
